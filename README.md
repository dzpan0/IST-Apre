# Overview

This project was developed as part of the Machine Learning (Apre) course at IST-UL.
The homeworks (HW) were written assignments and coding projects of the class (each had one part for us to calculate and answer questions and another for coding and analysing data using ML techniques).

- HW1
  - Decision Tree
- HW2
  - kNN and Naïve Bayes classifiers
- HW3
  - Regressions
- HW4
  - Clustering and PCA

# Structure

Each HW directory has: 
- `0* Homework 2025.pdf` - description of the homework
- `G114_report.pdf` - answers and analysis asked
- `G114_notebook.ipynb` - notebook used to create and analyse the model
- `*.csv` - data used to train the model and conduct the analysis of real world uses
- several images created while analysing the performance and other aspects of the model
