# Overview

This project was developed as part of the Machine Learning (Apre) course at IST-UL.
The homeworks (HW) were written assignments and coding projects of the class (each had one part for us to calculate and answer questions and another for coding and analysing data using ML techniques).

- HW1
  - Decision Tree
- HW2
  - kNN and Naïve Bayes classifiers
- HW3
  - Regressions
- HW4
  - Clustering and PCA
